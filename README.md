# Library Management System 


A Python-based Library Management System with an interactive Streamlit web interface.

## About the Project

This project is a Library Management System developed using Python.
The core library management logic is implemented in `main.py`, while 
`stream.py` provides a Streamlit-based web interface.

## Features

- Add and manage books
- Add and manage library members
- Borrow books
- Return books
- Track available book copies
- Generate unique Book and Member IDs
- Store data using JSON

## Project Files

- `main.py` - Contains the core Python logic of the Library Management System.
- `stream.py` - Provides the Streamlit web interface.
- `library.json` - Stores books and member data.

## Technologies Used

- Python
- Streamlit
- JSON
